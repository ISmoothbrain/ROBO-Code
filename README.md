# Robo-Code

## Description: 
This game is about learning how to code by battling enemies and progressing through levels. While you progress the challenges will increase in difficulty making it challenging and a fun way to test your knowledge.

This game has:

- Main menu
- Moveable player character
- Moving and attacking enemies
- Earn Currency
- Change Keybinds
- Brightness adjusting
- Turn base combat
- Usable Healing items
- Inventory
- Debug Challenges (Code questions)
- Unique enemies
- Defense and Attack
- Hack ability
- Visible health bar
- Item pickups
- Npc Interaction and Dialouge options
- Create Skills
- Music
- Difficulty
- Progression system
- An ending
- Side stories

## Installation:

Project Requirements:

Use a search engine and manually install:
- Unity Hub and then downlaod unity version 6000.5.6f to run the game files
- C# Compiler (Recomend Visual studio code)

PC Needed

### Getting Started:
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Open Unity Hub.**
3. Click **Add** > **Add project from disk**.
4. Select the root folder of the cloned repository.
5. Make sure you have the matching Unity version installed via Unity Hub, then click the project to open it.

### How to Play/ Controls
- **A, D:** Move Player
- **Spacebar:** Jumping
- **E:** Interact
- **F:** Item use
- **RightClick:** Equipping
- **LeftClick:** Attacking
- **ESC:** Pause
