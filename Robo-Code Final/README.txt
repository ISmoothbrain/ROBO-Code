HOW TO INSTALL
1. Close Unity. Back up your project (or commit to version control).
2. Extract this zip into your PROJECT folder (the one that contains Assets).
   (This zip does NOT include your scene, so nothing you've placed in the level is touched.)
3. Open Unity, check the Console has no red errors, press Play.

WHAT BUILDS ITSELF WHEN YOU PRESS PLAY
- The hooded hero as the Player (from Assets/Resources/PlayerCharacter)
- Hearts + mana HUD in the top-left (the old bars, coin counter and inventory panel are hidden)
- The Backpack (press I) with your coins in it
- Dialogue box, shop window, battle screen

CONTROLS
I = backpack   E = talk / shop   H = drink a potion   Esc = close windows

GO BACK TO THE OLD HERO
Rename or delete Assets/Resources/PlayerCharacter.overrideController.

ADDING THE SHOP
Drag Assets/Shop.prefab into the scene, place it on the ground, save the scene.
